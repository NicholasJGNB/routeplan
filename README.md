# 🧭 路径规划算法 · 网页互动讲解

一个**零依赖、纯前端**的交互式可视化页面，用动画把常见的路径规划算法从简单到复杂讲清楚。

直接用浏览器打开 `index.html` 即可，无需任何构建步骤。

## 它讲了哪些算法（由简到繁）

| 算法 | 一句话理解 | 考虑代价？ | 有方向感？ | 最优？ |
|------|-----------|:---:|:---:|:---:|
| **BFS 广度优先** | 像水波一圈圈扩散 | ❌ | ❌ | 步数最短 |
| **DFS 深度优先** | 一条路走到黑，撞墙再回头 | ❌ | ❌ | 否 |
| **Dijkstra** | BFS 的"会算账"升级版 | ✅ | ❌ | 总代价最优 |
| **贪婪最佳优先** | 只盯着终点猛冲 | ❌ | ✅ | 否（常绕远） |
| **A\*** | g（已走）+ h（还差），两全其美 | ✅ | ✅ | 最优且快 |

## 怎么玩

1. 左侧选一个算法，右侧读它的通俗讲解；
2. 在网格上**拖动鼠标**画 🧱 墙 / 🌧️ 沼泽（代价高），或拖动 🤖 起点、🎯 终点；
3. 点 **▶ 开始搜索**，看它一格格探索的动画，以及最终路径；
4. 底部统计会显示**探索格子数 / 路径长度 / 路径总代价**——切换算法对比，能直观看出"快"与"最优"的取舍。

试试「随机迷宫」，再分别跑贪婪和 A*，最能体会到差距。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 样式与动画
- `script.js` — 网格、交互、5 种算法与动画播放（含一个极简二叉堆优先队列）
